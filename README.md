- **Estilos:** Tailwind CSS con modo oscuro / claro dinámico

## 🚀 Instalación y Ejecución Local

### Prerrequisitos
- **Node.js:** v20+ o v22+
- **npm:** v10+

### Pasos

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/Alejandrom199/saulmaldonado.dev.git
   cd saulmaldonado.dev/cv-web
   ```

2. Instalar dependencias:
   ```bash
   npm install
   ```

3. Iniciar el servidor de desarrollo:
   ```bash
   npm start
   ```
   Navegar a `http://localhost:4200/`.

4. Compilación de producción:
   ```bash
   npm run build
   ```

5. Ejecución de pruebas unitarias:
   ```bash
   npm test
   ```
